# 声语 · 对话情绪观察

一个无需安装依赖的中文网页原型，可在浏览器中录制语音、读取音频特征，并结合对话文本生成情绪线索、沟通建议和互动观察。

## 启动

建议使用 Chrome 或 Edge。在项目目录运行：

```powershell
python -m http.server 8000
```

然后打开 `http://localhost:8000`。录音功能需要在 `localhost` 或 HTTPS 页面中运行，并允许浏览器访问麦克风。也可以直接打开 `index.html` 使用文本分析和部分音频文件分析。

## 发布到 GitHub Pages

仓库已包含 Pages Actions 工作流。将 `main` 分支推送到 GitHub 后，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**；工作流完成后，页面会自动发布，并在仓库的 Pages 设置中显示网址。之后每次推送到 `main` 都会自动更新网站。

此应用是纯静态网页，不需要构建步骤、后端服务或 API 密钥。录音、人工标注和训练出的模型保存在访问者自己的浏览器本地，不会写入 GitHub。

## 使用

- **录音与转写**：点击开始录音。浏览器支持时会实时提供中文转写；录音结束后，也可点击“中文转写”使用 Whisper tiny 在当前浏览器运行识别。首次使用需联网下载语音模型和运行时，下载后会使用浏览器缓存。
- **中文语义分析**：转写后可梳理对话话题、表达的需要、回应和行动约定，再结合词语与简化音频特征显示情绪线索、互动观察和沟通建议。自动转写不会区分说话人；请核对内容，并手动给不同发言加上“我：”“对方：”等标签。
- **上传音频**：选择或拖入音频文件。点击“中文转写”即可在浏览器本地识别录音；音频不会上传到模型服务。转写文字会填入对话文本框，识别后请自行核对。
- **截取与标注**：在右侧波形上按住并拖动选择片段，最短 0.25 秒；填写情绪、说话人、标注把握程度和备注，再保存。片段可单独试听、删除，时间区间会在波形中标出。
- **录音库**：每次载入新的录音或音频都会作为一份独立标注素材保存在本地录音库，可从列表切换，先前片段不会被覆盖。
- **导出训练集**：下载 ZIP，包含每段独立 PCM WAV、`labels.jsonl`、`labels.csv` 和情绪字典。清单记录起止秒数/毫秒数、情绪代码、说话人、标注把握度、备注、采样率和声道数。可用于数据审阅和后续模型训练。
- **训练本地模型**：录音库可以累积多段音频及其标注。点击“训练 / 更新模型”，页面会读取录音库所有标注片段，提取 16 kHz、24 维 Log-Mel 频谱统计量与能量/过零特征，以带类别平衡的 softmax 线性分类器训练多分类情绪模型。模型权重存入浏览器 IndexedDB，也可另存为 JSON；选择新音频中的区间后可运行本地预测。
- **对话文本**：按“我：……”和“对方：……”逐行输入。示例内容可以一键载入。

当前情绪标签为一套可迭代的工作标签（平静、开心、难过、愤怒、焦虑、平和、厌恶、害怕、其他），并非唯一通用标准。训练前建议固定各标签定义、统一标注规范，并检查说话人泄漏、类别平衡和录音授权。

## 当前实现与限制

- 语义卡片从中文转写文本中的话题、请求、感受和行动表达归纳，属于可解释的规则摘要，不等同于完整理解语境的对话大模型。
- Whisper tiny 的识别准确度受口音、噪声和说话重叠影响；它不会自动分离说话人。语音模型和运行时代码从 Hugging Face 与 jsDelivr 加载，首次使用需要网络，原始音频仍在浏览器本地处理。
- 情绪线索来自少量中文词语规则；音频侧使用音量、过零率等简化信号特征，不能可靠地从声音特征单独推断情绪。
- 页面百分比表示规则线索强度，不是经过训练或校准的情绪概率。
- 互动分析通过文本规则观察请求、回应、道歉和否定表达，不会识别真实的人物身份，也不能判断亲密关系、人格或心理健康状况。
- 浏览器原生语音转写的可用性和数据处理方式由浏览器提供方决定。若不希望使用该服务，可直接粘贴已有文本。
- 音频和标注存放在浏览器 IndexedDB 中；清除网站数据会移除本地工作区，请定期导出训练集备份。
- 训练至少需要两种情绪、每种两段标注；每类达到 5 段时会留出验证样本并报告准确率和 Macro-F1。样本少时不显示验证分数；正式使用建议每类收集更多、覆盖不同说话人的样本，并按说话人隔离验证集。
- 本地训练器是轻量基线，使用固定 Log-Mel 统计特征和线性分类器，不是大型端到端语音模型。预测分数未校准，且会受录音设备、语言和说话人影响；它适合快速迭代标签和建立基线，不能视为可靠的通用情绪识别器。
- 浏览器内模型训练使用录音库中的所有标注；训练集 ZIP 导出按钮对应当前选中的录音。

此原型提供沟通参考，不是心理诊断或关系结论。
